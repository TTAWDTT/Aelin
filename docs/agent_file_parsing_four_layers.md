Agent解析文件内容并做出回答的功能分四层实现，第一层为文件接入层，负责文件接入、元数据管理、文件缓存、文件存储；第二层为解析层，将各类型文件转换成统一的document对象，其中，PDF文件需对文本层和非文本层进行处理，文本层提取文本及坐标拼成页面文本，非文本层利用OCR直接提取出文本或利用图像处理概括出文本内容；DOCX / PPTX / XLSX本质是一个 zip 包，里面是很多 xml 文件（带标签的结构化文本），按标签还原出标题、段落、表格、图片、备注等结构；doc/ppt/xls先转新格式（docx/pptx/xlsx）后按照新格式解析；第三层为索引层，将解析得到的文件进行切分（chunk)、向量化、写入索引的处理，让 Agent 能瞬间找到相关内容片段；第四层为问答编排层，让Agent解析用户问题、调用工具、处理索引结果、生成回答。
