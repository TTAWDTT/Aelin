# Aelin 六模块统一视觉草案（v1）

## 总体目标
- 统一为纯黑/纯白主轴的极简样式，去掉多余嵌套框线和强调色噪音。
- 所有页面复用同一套布局与组件语言，保证“像同一个产品”。
- 保持桌面端 iPhone 比例体验，侧栏承载核心模块导航。

## 全局设计令牌
- 颜色：`black / white / gray` 三阶系统，浅色深色仅语义翻转。
- 形状：`12px` 统一圆角，避免多级异形圆角。
- 间距：`8px` 网格；主页面宽度和输入区按同一中线对齐。
- 动效：仅保留必要过渡（hover/focus/主题切换），禁用花哨动画。

## 六模块信息架构
1. `Chat`：主对话入口，中心输入框与消息区严格对齐。
2. `Tracking`：追踪目标与变化流。
3. `Processes`：进程管理（高信息密度，但同色板）。
4. `Aelinの日记`：OpenViking 记忆文件流（Markdown 预览）。
5. `Focus`：专注模式开关与状态说明（通知静默）。
6. `Settings`：账号、模型、外观、设备配置。

## 桌宠与入口
- 侧栏顶部使用 Aelin 头像（`desktop/build/icon.ico` 同步到前端资源）作为桌宠入口替代。
- 不额外引入 GIF 桌宠逻辑，先保证入口形象与导航统一。

## 实施顺序
1. 全局主题与布局壳层统一（token + sidebar + page scaffold）。
2. Chat 模块精修（排版、输入框、状态条、消息卡）。
3. Tracking / Processes 模块统一风格。
4. Focus / Diary 新模块落地。
5. Settings 收口与冗余代码清理。
