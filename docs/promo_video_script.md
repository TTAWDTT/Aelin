# Aelin 宣传视频脚本方案

## 核心价值 (The Hook)
"Beyond Chat: Aelin is your local AI workspace with deep model agency and persistent memory."

## 视频段落 (Scenes)

### Scene 1: Intro (0-3s)
- **视觉**: Aelin Logo 居中，背景使用深色渐变（与品牌色一致）。
- **文字**: Aelin - 您的智能 AI 工作空间。
- **动画**: Logo 缩放进入，伴随轻微的回弹效果。

### Scene 2: DeepAgents Core (3-8s)
- **视觉**: 展示 Agent Server 的拓扑结构或 LangGraph 工作流示意图。
- **文字**: 由 DeepAgents 提供动力。
- **关键点**:
  - 多步推理 (Multi-step reasoning)
  - 自动任务执行 (Autonomous task execution)

### Scene 3: Powerful Tools (8-15s)
- **视觉**: 快速图标滑动：Web Search, Google Workspace, Device Control, Screen Capture。
- **文字**: 内置强大工具集。
- **动画**: 每个工具图标交替出现，伴随淡入淡出。

### Scene 4: Persistent Memory (15-20s)
- **视觉**: 展示 `AGENTS.md` 文件内容滚动的动画。
- **文字**: 基于文件的长期记忆。
- **关键点**: 跨会话一致性，用户可控。

### Scene 5: Desktop Runtime (20-25s)
- **视觉**: 模拟桌面窗口（Electron）运行 Aelin 的界面。
- **文字**: 本地桌面原生体验。

### Scene 6: Outro (25-30s)
- **视觉**: 品牌 Logo 再次出现，加上 GitHub 仓库地址。
- **文字**: 立即开始您的 AI 探索。
- **行动呼吁**: [github.com/Aelin](https://github.com/Aelin)

## 视觉风格 (Visual Identity)
- **主色调**: 深色/深蓝背景 (#0f172a)，文字白色或浅蓝。
- **字体**: 使用 Google Fonts (如 Inter 或 Roboto)。
- **动画风格**: 平滑、现代，大量使用 `spring` 动画 (damping: 200)。
